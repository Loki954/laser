# Loki Laser

Android app (phone and tablet) for SculpFun laser engravers — engrave, cut, cut-around shapes, trace with the blue dot, material presets.

## Install
1. Open the **[latest release](https://github.com/Loki954/laser/releases/latest)** on your Android phone or tablet.
2. Download **Loki-Laser.apk** and open it. Allow installing from this source if Android asks.

The app checks for updates by itself and installs new versions from inside the app.
